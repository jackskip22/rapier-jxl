# Agent Skills

| Skill | Use |
| --- | --- |
| [rapier-jxl-single-file-app](rapier-jxl-single-file-app/SKILL.md) | Inline JPEG XL encoding in an offline HTML app. |
| [rapier-jxl-photography](rapier-jxl-photography/SKILL.md) | Preserve pixels, precision, color meaning, and Exif/XMP; create photographic derivatives. |

Install either directory with an [Agent Skills](https://agentskills.io/) compatible tool, or copy it into the agent's
project skill directory, such as `.agents/skills/`. Each skill is self-contained; reference links work when copied.
The package includes the same directories under `skills/`. Skills provide instructions; install `rapier-jxl` for the encoder.
