# Encoder payloads measured on 30 September 2026

Rapier JXL is the smallest JavaScript/WebAssembly JPEG XL encoder **among the published payloads measured here**.
This is a bounded survey, not proof of the smallest possible implementation. The alternatives implement different
subsets of JPEG XL. In particular, Rapier's JPEG carrier preserves coefficients but cannot reconstruct the original
JPEG file; libjxl's reversible JPEG mode can. Larger codecs also offer features Rapier does not, including HDR,
ICC profiles, animation, perceptual search and more compression tools.

Bytes are decimal, not KiB. Every listed file, upstream URL, npm archive integrity and SHA-256 is in
[`public/encoder-sizes.json`](public/encoder-sizes.json). JavaScript is minified with Terser 5.51.2
(`compress.passes=2`, mangling, license comments retained); shipped WASM is unchanged. Each resource is gzipped
independently at level 9, then sizes are summed. These are delivery bytes, not npm tarball sizes. Rapier's
`sizes.json` records its independently optimized single-file builds and complete MIT banner.

The jSquash, fork, squoosh-kit and icodec rows count the low-level encoder factory and its WASM. Optional
convenience wrappers, threaded variants, workers and decoders are excluded. This favors those alternatives;
it does not pretend the entire npm package is needed to encode one picture. The Squoosh library has shared
JavaScript, so that file is included whole. The JPEG-to-JXL package also exposes reverse conversion from the
same WASM; it is not an encoder-only custom rebuild. Size measurements do not establish the other packages'
correctness or compression quality.

## Reproduce

In a checkout of this public repository:

```sh
npm install --ignore-scripts
node public/measure-encoders.mjs .encoder-size-cache encoder-sizes.json
```

The script fetches only pinned npm archives from `public/encoders.json`, validates their integrity, reads the
listed members in memory and minifies their JavaScript. It never installs or executes downloaded competitor
code. The cache makes repeats offline. Rapier's own byte receipt is generated by its source stager, not by
this survey. For a standalone copy of the script, install `terser@5.51.2` first.
